**Первый за неделю день, где рынок двигают не внешние каналы, а мой
собственный календарь, и в нём сразу два события первого ранга

пресс-конференция Лагард в 12:45 и макропрогнозы в 13:45. Само

живёт в трёх местах: в прогнозах по инфляции, в том, подтвердит ли
Лагард заложенные рынком 47 базисных пунктов до конца года, и в том,
насколько сильно энергия протолкнула американский PPI. Направление
дня заранее не выводится ни из одного из них, поэтому база опускается
до 30% по калибровочной таблице, полосы расширяются до медианы
четверга, а точка считается не уклоном, а взвешенным средним центров
трёх сценарных зон.**

Три опоры тезиса:

1. **Календарь наконец сильнее внешних каналов.** Три дня подряд
   день делали иена, нефть и объявление Минфина, а мои релизы
   не давали ни пипса. Сегодня наоборот: два события первого ранга
   в одном получасе, оба с проверяемым временем по первоисточникам.
   Иеновый импульс при этом затухает третьи сутки (-193, -47,
   -17 пунктов за ночи понедельника, среды и сегодня).
2. **Единодушие превью максимальное, и это довод против единодушия.**
   65 из 65 по решению; и FXStreet, и investingLive пишут одно
   и то же про Лагард - "сохранит опциональность, сигнала не даст".
   По ловушке 12 это значит, что цена содержательного сигнала

## Как выбраны точки: сегодня уклона нет вообще

По README точка при базе меньше 50% считается **как взвешенное
среднее центров трёх сценарных зон**, а не как якорь плюс уклон.
Правило записано после 28.08 и до сегодня системно не применялось.
Сегодня применяется ко всем четырём парам сразу - это и есть замена
уклона, который девять дней подряд не окупался.

Второе изменение метода, сегодня же: **точка фунта считается
из его собственных зон, а не выводится из EURUSD и EURGBP**. Дефект
"точка фунта несёт сумму двух уклонов" записан шесть раз подряд;
сегодня он лечится прямо, а деривативное значение остаётся
как контроль.

### Снос EURCHF: четвёртая проверка, и правило меняет форму

Счёт правила: 07.09 обнуление выиграло 17 п, 08.09 снос +12 п
проиграл 3.8 п, 09.09 снос +4 п выиграл 2.0 п. Вчерашний разбор
показал, почему медиана - плохая оценка: она скачет от +4.5 до +11.8
в зависимости от одного дня, а фактический дрейф вчера был +15.1 п
при заложенных +4.

Поэтому с сегодняшнего дня берётся **кандидат-замена: фиксированные
+5 пипсов, когда есть американская сессия**. Обоснование - не величина,
а знак: дрейф EURCHF был положительным **три дня из трёх подряд**
(+0.4, +15.1 и +18.1 п до этого), франк устойчиво слабеет к евро.
Медиана десяти дней с сессией сегодня равна **+8.1 п** и в расчёт
не берётся - она записана только для сравнения вечером.

**Проверка согласованности точек:** EURGBP из точек = 1.1630 / 1.3542
= 0.85881 против опубликованного 0.8587 - **1.1 пипса** (было 7.5 п
вчера при выводе фунта из кросса). EURCHF из точек = 1.1630 x 0.8107
= 0.942844 против якорного 0.942257 - **+5.9 п**, то есть снос
плюс округление.

**База сравнения (обязательная строка):** точка на якоре -
1.16328 / 1.35458 / 0.81000 / 0.85858. Вечером её ошибка считается
наравне с ошибкой опубликованной точки.

**Записано до факта: у EURGBP сдвиг точки 1.2 пипса, то есть меньше
порога вырожденности 2 п.** По правилу README направление по кроссу
сегодня помечается `n/a` и в счёт направления не идёт. Это не отговорка
задним числом - у меня действительно нет направленного взгляда
на кросс в день, когда событие есть только у одной его половины,
и оно полностью в цене.

**Центры полос против якоря:** 0.0 / 0.0 / 0.0 / 0.0 п. Четвёртое
применение правила центрирования.

Почему сегодня решающий день для max(): вчера правило дало 3/3,
но день оказался тихим (размахи 70-83% ADR(5)), и попали бы обе
версии - это было записано в разборе как "настоящей проверки
не было". Сегодня медиана дня недели у трёх пар из четырёх заметно
больше ADR(5), то есть версии расходятся сильно: среднее дало бы
48 / 61 / 57 / 20 против взятых 56 / 69 / 59 / 22. И день событийный,
то есть шанс, что размах превысит ADR(5), высокий.

**Что сознательно не применено.** В калибровочной таблице README
есть строка "на дне долларового события пары с долларом берут
160-170% медианы размаха этого дня недели". Она сегодня **не
применяется**, потому что тогда проверка правила max() смешалась бы
с проверкой событийного множителя, и вечером нельзя было бы понять,
что сработало. Для протокола: множитель дал бы 90-96 / 111-117 /
95-101 п. Если факт ляжет между моей шириной и этим числом, вывод
будет в пользу множителя, и это записано **до** факта.

## Что проверяется этим прогнозом отдельно

1. **Ширина = max(ADR(5), медиана дня недели)** - второе применение
   и первое настоящее: медианы четверга у трёх пар больше ADR(5)
   на 9-40%, версии расходятся сильно, день событийный. Событийный
   множитель 160-170% из README сознательно не применён, его значения
   записаны выше **до** факта.
2. **Точка как взвешенное среднее центров зон** вместо якоря плюс
   уклон - первое системное применение ко всем четырём парам.
   Считается вместе с точкой на якоре.
3. **Точка фунта из собственных зон**, а не выведенная из евро
   и кросса - лечение дефекта, записанного шесть раз. Деривативное
   значение 1.35437 записано как контроль, расхождение 1.7 п.
4. **Снос EURCHF - фиксированные +5 п** вместо медианы. Вечером
   обе версии, 0.8107 и 0.8102, плюс справочно версия по медиане
   +8.1 п.
5. **Тихий период проверен для обоих ЦБ** (правило от 09.09):
   до 12:15 UTC ни ЕЦБ, ни ФРС не могут сказать ничего по существу.
   Из-за этого база **не** понижалась под утренние выступления,
   как это ошибочно было сделано вчера.
6. **Пороги на внешние каналы поставлены от дневного размаха самого
   канала**, а не от круглых уровней и годовых максимумов - прямое
   следствие вчерашнего разбора, где ни один из пяти внешних порогов
   не сработал в день, сделанный внешним каналом.
7. **База 30% на дне первого эшелона** - по калибровочной таблице
   README (день релиза первого эшелона: база сбылась 0 из 11,
   рекомендованное значение 25%). Взято чуть выше 25%, потому что
   два из трёх событий дня - это коммуникация, а не число.
