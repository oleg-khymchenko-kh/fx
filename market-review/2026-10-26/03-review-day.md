## Разбор ошибок метода

### Ошибка 1. Наклон 0 из 2, и риск был назван числом утром

Правило наклона (бакет ночного хода, порог хода 0.25 ADR
плюс порог доли продолжения 70%) поставило наклон евро
и франку. Оба закрытия ушли **за якорь**, то есть в те
28.7% и 29.0%, которые утренний файл назвал главным риском
наклона. Накопленный счёт наклона по направлению:
**13 из 16 до сегодня, 13 из 18 после**; средняя ошибка
точек с наклоном **20.2 -> 22.9 пипса**.

Что здесь важно отделить: **правило не сломалось, выпал
его измеренный хвост** - и выпал у двух пар сразу, что
при корреляции долларовых пар внутри дня не независимые
два события, а одно. **Запись: 71% доли продолжения
по каждой паре в отдельности не означает 71% по дню,
если наклоны у пар однонаправленные по доллару.**
Сегодня оба наклона были долларовыми (евро вверх = доллар
вниз, франк вниз = доллар вниз), то есть один наклон
на доллар, поставленный дважды. **Кандидат на правило:
считать долю продолжения не по парам, а по валюте,
против которой ставится наклон; при однонаправленных
наклонах уменьшать множитель.** Применять не раньше
второй независимой проверки.

### Ошибка 2. Контроль 23 выиграл там, где утром был назван главным риском дня

## Что записано в правила

1. **Кандидат (нужна вторая независимая проверка): доля
   продолжения считается по валюте, а не по паре.**
   Сегодня оба наклона были одним долларовым наклоном,
   поставленным дважды, и выпали вместе. Заявленные 71%
   по паре не дают 71% по дню, если наклоны однонаправлены
   по доллару.
2. **Запись: контроль 23 (тонкий бакет) в первом же
   различимом дне выиграл видом решения, 15.1 пипса
   у франка.** Счёт по видам решения 1 из 1. Конструкция
   не меняется (правило "конструкция не меняется между
   днями"), но долг утреннего замера 1 - доверительный
   интервал доли при n = 200-210 - становится условием
   для любого решения о тонком бакете.
3. **Запись: контроль 32 (понедельничная подвыборка)
   открыл счёт 0 из 1, и промах пришёл с пары с самой
   тонкой выборкой** (кросс, n = 34 вне выборки). Долг

4. **Запись: преимущество полосы B исчезло за один день.**
